Its current state is described by a jump vector ($$$a, b$$$): when the engine is activated, the ship moves by $$$a$$$ units along the first coordinate and by $$$b$$$ units along the second coordinate. Since it is not always possible to reach the station exactly, he wants to stop at a valid point as close as possible to ($$$x, y$$$).</p><p>Help Hypercarp choose the number of moves and engine parameter increases during these moves so that the ship stops at a valid point ($$$p, q$$$) for which the squared Euclidean distance to the station is minimized.
